# EcoTrace AI Website

A lightweight marketing homepage for EcoTrace AI, built with plain HTML, CSS and JavaScript.

## Run locally

No build tools or package installation required.

1. Download or clone this repository.
2. Open `index.html` in your browser.

For a local development server, from the project folder run:

```bash
python3 -m http.server 5500
```

Then visit `http://localhost:5500`.
